Key Features

Remote Execution

Run shell commands natively on target machines. AI agents can analyze logs, restart services, or debug system states in real-time.

SFTP File Transfer

Bidirectional file transfer capability. Agents can safely upload configuration files or download database dumps for analysis.

Enterprise Security

Strict path allowlists, command timeouts, key-based authentication, and payload size limits ensure your infrastructure remains secure.

Powerful Use Cases

Transform how you interact with your systems by making them conversational.

Automated SysAdmin

Ask Claude to "check why the web server is slow." The agent will SSH in, run `top`, check `/var/log/nginx`, analyze the results, and propose a fix—all in one conversation.

CI/CD & Deployments

Direct your AI assistant to "deploy the latest build to staging." The bridge allows the agent to upload the artifacts via SFTP, stop the service, swap binaries, and restart.

Database Troubleshooting

Agent can securely connect to a jump host, run SQL queries via CLI, fetch the schema, and help you optimize slow queries based on live execution plans.

Security Auditing

Task the LLM with verifying security configurations. It can scan open ports, read SSH configs, and ensure compliance without needing a complex security agent installed.

# 1. Install via pip
pip install ssh-mcp-bridge

# 2. Configure your SSH targets
cp ssh_mcp.yaml.example config.yaml

# 3. Add to Claude Desktop Config
{
  "mcpServers": {
    "ssh-bridge": {
      "command": "python",
      "args": ["-m", "ssh_mcp_bridge", "--config", "/path/to/config.yaml"]
    }
  }
}
